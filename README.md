# Cruising Companion

Create a multiplayer freeride game interface with a modern in‑game smartphone.
The world has auto‑driving cars with auto‑turn, auto‑stop, seatbelt requirement, and collision‑prevention.
Design the phone UI with apps for Calls, Google Maps, and Invite‑to‑Car.
Include a clean, minimal style with smooth animations.
The game has no missions, only exploration and social interaction.
Cars move automatically and players interact through the phone system.
Build screens for:

Phone home screen

Call interface

Google Maps navigation

Seatbelt warning

Invite‑to‑car menu
Make everything look friendly, safe, and easy to use.
