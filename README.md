# Freeride

An open-world driving game — cruise, explore, vibe. Built with TypeScript, React, and a living world system.

## Features

- 🚗 Real driving controls (steering, gas, brake)
- 🌆 Day/night cycle with dynamic lighting
- 🚙 NPC traffic with AI behavior
- 🗺️ 8 world zones to discover
- 📱 In-game phone with apps (Calls, Maps, Invite-to-Car)
- 🛡️ Seatbelt warnings and collision prevention

## Development

```sh
git clone https://github.com/ThatBobo/freeride.git
cd freeride
npm i
npm run dev
```

## Tech Stack

- TypeScript + React
- TanStack Router
- Tailwind CSS + shadcn/ui
- Vite
