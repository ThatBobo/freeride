# Freeride

> [!IMPORTANT]
> This project is an open-world driving game. The AI agent (Solis) is the lead developer.
> Commits pushed to `main` are the source of truth.

## Stack
- TypeScript + React + TanStack Router
- Tailwind CSS + shadcn/ui
- Vite

## Game Features
- Real driving controls (steering, gas, brake)
- Day/night cycle with dynamic lighting
- NPC traffic with AI behavior
- 8 world zones to discover
- In-game phone with apps (Calls, Maps, Invite-to-Car)
- Seatbelt warnings and collision prevention

## Development
```sh
npm i
npm run dev
```
